# flow/traits

**Severity:** see the rule pack. **Network:** not required

## What it checks

MetadataViews traits: name and value.

## Why it matters

Marketplaces filter on the trait name as written, so the name should be the label collectors see.

## How to fix

Each trait needs a name and a string or number value.
