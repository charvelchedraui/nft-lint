# stargaze/attributes

**Severity:** see the rule pack. **Network:** not required

## What it checks

Attributes on the extension or the top-level JSON.

## Why it matters

Stargaze reads trait_type and value, the same shape as OpenSea.

## How to fix

Each attribute needs a non-empty trait_type and a string or number value.

Docs: https://github.com/charvelchedraui/nft-lint/blob/main/docs/rules/stargaze/attributes.md
