# common/youtube-url

**Severity:** see the rule pack. **Network:** not required

## What it checks

youtube_url.

## Why it matters

Marketplaces only embed YouTube. A Vimeo link is not a youtube_url.

## How to fix

Use https://www.youtube.com/watch?v=..., /shorts/..., /embed/..., or https://youtu.be/...

Docs: https://github.com/charvelchedraui/nft-lint/blob/main/docs/rules/common/youtube-url.md
